# Calling Bell Final App

Calling Bell — All Local Services, One Powerful Platform.

This branch contains the new dashboard implementation based on the supplied Calling Bell AI code-generation context and dashboard reference.

Stack: React 19 + TypeScript + Vite, ASP.NET Core/.NET 10, EF Core, SQL Server, REST API version 1.

The complete local project package is supplied separately as CallingBellFinalapp.zip. This branch is staged under the existing penuballisrku/callingbell repository because the connected GitHub integration does not expose GitHub's create-new-repository operation.

Core dashboard data is API-driven through GET /api/v1/dashboard; production data belongs in SQL Server.
